# Queue Data Structure in C++

This repository contains the implementation of the **Queue Data Structure** in **C++**. The programs are designed to help beginners understand the **FIFO (First In, First Out)** principle using Object-Oriented Programming concepts and dynamic memory allocation.

## Topics Covered

### Queue Operations

* Enqueue
* Dequeue
* Front (Peek)
* Display Queue
* Count Elements

## Concepts Used

* Queue Data Structure
* FIFO (First In, First Out)
* Classes and Objects
* Dynamic Memory Allocation (`new`, `delete`)
* Pointers
* Linked List Implementation
* Menu-Driven Programming

## Learning Objectives

This repository helps in understanding:

* Working of the Queue data structure
* Enqueue and Dequeue operations
* Dynamic memory allocation using `new` and `delete`
* Pointer manipulation
* Queue traversal
* Handling Queue Underflow conditions
* Object-Oriented Programming concepts in C++
