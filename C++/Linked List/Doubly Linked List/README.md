# C++ Doubly Linked List Data Structure

This repository contains a complete implementation of the **Doubly Linked List (DLL)** Data Structure in C++. The programs are designed to help understand bidirectional node linking, dynamic memory allocation, pointer manipulation, and object-oriented programming concepts through practical examples.

## Topics Covered

### Doubly Linear Linked List

* Insert First
* Insert Last
* Insert At Position
* Delete First
* Delete Last
* Delete At Position
* Display Elements
* Count Nodes

## Concepts Used

* Classes and Objects
* Dynamic Memory Allocation
* Pointers
* Self-Referential Structures
* Encapsulation
* Data Structure Design
* Forward and Backward Traversal
* Memory Management

## Learning Objectives

This repository helps in understanding:

* Internal working of Doubly Linked Lists
* Node creation and bidirectional linking
* Dynamic insertion and deletion operations
* Forward and backward traversal techniques
* Pointer manipulation using next and prev links
* Object-Oriented Programming concepts in C++
