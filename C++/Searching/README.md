# Searching Algorithms in C++

This repository contains the implementation of **Searching Algorithms** in **C++**. The programs are designed to help beginners understand how to efficiently search for an element in a collection of data using Object-Oriented Programming concepts.

## Topics Covered

### Searching Algorithms

* Linear Search
* Binary Search

## Concepts Used

* Searching Algorithms
* Arrays
* Classes and Objects
* Linear Search
* Binary Search
* Iterative Programming
* Conditional Statements
* Time Complexity Analysis

## Learning Objectives

This repository helps in understanding:

* Working of Linear Search
* Working of Binary Search
* Difference between Linear Search and Binary Search
* Sequential and Divide-and-Conquer searching techniques
* Searching elements in sorted and unsorted arrays
* Time complexity analysis of searching algorithms
* Object-Oriented Programming concepts in C++
