# Stack Data Structure in C++

This repository contains the implementation of the **Stack Data Structure** in **C++**. The programs are designed to help beginners understand the **LIFO (Last In, First Out)** principle using Object-Oriented Programming concepts and dynamic memory allocation.

## Topics Covered

### Stack Operations

* Push
* Pop
* Peek (Top Element)
* Display Stack
* Count Elements

## Concepts Used

* Stack Data Structure
* LIFO (Last In, First Out)
* Classes and Objects
* Encapsulation
* Dynamic Memory Allocation (`new`, `delete`)
* Pointers
* Linked List Implementation
* Menu-Driven Programming

## Learning Objectives

This repository helps in understanding:

* Working of the Stack data structure
* Push and Pop operations
* Dynamic memory allocation using `new` and `delete`
* Pointer manipulation
* Stack traversal
* Handling Stack Overflow and Underflow conditions
* Object-Oriented Programming concepts in C++
