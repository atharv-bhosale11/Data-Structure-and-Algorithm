# Queue Data Structure in C

This repository contains the implementation of the **Queue Data Structure** in **C**. The programs are designed to help beginners understand the **FIFO (First In, First Out)** principle, queue operations, and dynamic memory management using linked lists.

## Topics Covered

### Queue Operations

* Enqueue
* Dequeue
* Front (Peek)
* Display Queue
* Count Elements

## Concepts Used

* Queue Data Structure
* FIFO (First In, First Out)
* Linked List Implementation
* Dynamic Memory Allocation (`malloc`, `free`)
* Pointers
* Self-Referential Structures
* Traversal Techniques
* Menu-Driven Programming

## Learning Objectives

This repository helps in understanding:

* Working of the Queue data structure
* Enqueue and Dequeue operations
* Dynamic memory allocation
* Pointer manipulation
* Queue traversal
* Handling Queue Underflow conditions
* Building menu-driven applications in C
