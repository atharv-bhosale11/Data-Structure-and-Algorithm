# Tree Data Structure in C

This repository contains implementations of **Tree Data Structure** in **C Programming**. It covers basic tree concepts, node creation, insertion, traversal techniques, and other common tree operations used in data structures.

## Topics Covered

- Tree Introduction
- Terminologies of Tree
- Binary Tree
- Binary Search Tree (BST)
- Node Creation
- Insert Operation
- Search Operation
- Tree Traversals
  - Inorder Traversal
  - Preorder Traversal
  - Postorder Traversal
- Count Nodes
- Count Leaf Nodes
- Count Parent Nodes
- Calculate Height of Tree

## Technologies Used

- Language: C
- Compiler: GCC / Turbo C
- Platform: Windows / Linux

## Learning Objectives

- Understand hierarchical data structures.
- Learn tree node creation and linking.
- Implement insertion and searching in trees.
- Perform different traversal techniques.
- Solve problems using recursive algorithms.
