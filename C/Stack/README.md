# Stack Data Structure in C

This repository contains the implementation of the **Stack Data Structure** in **C**. The programs are designed to help beginners understand the **LIFO (Last In, First Out)** principle, stack operations, and dynamic memory management using linked lists.

## Topics Covered

### Stack Operations

* Push
* Pop
* Peek (Top Element)
* Display Stack
* Count Elements

## Concepts Used

* Stack Data Structure
* LIFO (Last In, First Out)
* Linked List Implementation
* Dynamic Memory Allocation (`malloc`, `free`)
* Pointers
* Self-Referential Structures
* Traversal Techniques
* Menu-Driven Programming

## Learning Objectives

This repository helps in understanding:

* Working of the Stack data structure
* Push and Pop operations
* Dynamic memory allocation
* Pointer manipulation
* Stack traversal
* Handling Stack Overflow and Underflow conditions
* Building menu-driven applications in C
