# Java Doubly Circular Linked List Data Structure

This repository contains an implementation of the **Doubly Circular Linked List** Data Structure in Java. The project demonstrates circular node linking, bidirectional traversal, and dynamic data management using Object-Oriented Programming principles.

## Features

### Doubly Circular Linked List Operations

* Insert First
* Insert Last
* Insert At Position
* Delete First
* Delete Last
* Delete At Position
* Display Elements
* Count Nodes

## Concepts Used

* Classes and Objects
* Object-Oriented Programming (OOP)
* References and Objects
* Doubly Circular Linked List
* Circular Traversal
* Bidirectional Linking
* Encapsulation
* Data Structure Design

## Learning Objectives

This repository helps in understanding:

* Internal working of Doubly Circular Linked Lists
* Circular node connections using next and prev references
* Dynamic insertion and deletion operations
* Forward and backward traversal techniques
* Reference manipulation in Java
* Memory-efficient data organization
* OOP-based implementation of linked lists
