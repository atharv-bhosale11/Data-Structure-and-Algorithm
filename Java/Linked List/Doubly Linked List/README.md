# Java Doubly Linked List Data Structure

This repository contains an implementation of the **Doubly Linked List** Data Structure in Java. The project is designed to help understand node linking, bidirectional traversal, dynamic memory management, and common linked list operations using Object-Oriented Programming concepts.

## Features

### Doubly Linked List Operations

* Insert First
* Insert Last
* Insert At Position
* Delete First
* Delete Last
* Delete At Position
* Display Elements
* Count Nodes

## Concepts Used

* Classes and Objects
* Object-Oriented Programming (OOP)
* Dynamic Memory Allocation
* References and Objects
* Doubly Linked List
* Bidirectional Traversal
* Encapsulation
* Data Structure Design

## Learning Objectives

This repository helps in understanding:

* Internal working of Doubly Linked Lists
* Node creation and linking
* Forward and backward traversal
* Dynamic insertion and deletion operations
* Reference manipulation
* Memory-efficient data organization
* Java OOP implementation of data structures
