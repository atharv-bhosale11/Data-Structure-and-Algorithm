# Stack Data Structure in Java

This repository contains the implementation of the **Stack Data Structure** in **Java**. The programs are designed to help beginners understand the **LIFO (Last In, First Out)** principle using Object-Oriented Programming concepts.

## Topics Covered

### Stack Operations

* Push
* Pop
* Peek (Top Element)
* Display Stack
* Count Elements

## Concepts Used

* Stack Data Structure
* LIFO (Last In, First Out)
* Classes and Objects
* Constructors
* References
* Linked List Implementation
* Menu-Driven Programming

## Learning Objectives

This repository helps in understanding:

* Working of the Stack data structure
* Push and Pop operations
* Displaying stack elements
* Counting the number of elements
* Pointer (Reference) manipulation
* Handling Stack Overflow and Underflow conditions
* Object-Oriented Programming concepts in Java
