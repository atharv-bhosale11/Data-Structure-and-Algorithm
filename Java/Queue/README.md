# Queue Data Structure in Java

This repository contains the implementation of the **Queue Data Structure** in **Java**. The programs are designed to help beginners understand the **FIFO (First In, First Out)** principle using Object-Oriented Programming concepts.

## Topics Covered

### Queue Operations

* Enqueue
* Dequeue
* Front (Peek)
* Display Queue
* Count Elements

## Concepts Used

* Queue Data Structure
* FIFO (First In, First Out)
* Classes and Objects
* Encapsulation
* Constructors
* References
* Linked List Implementation
* Menu-Driven Programming

## Learning Objectives

This repository helps in understanding:

* Working of the Queue data structure
* Enqueue and Dequeue operations
* Displaying queue elements
* Counting the number of elements
* Reference manipulation
* Handling Queue Overflow and Underflow conditions
* Object-Oriented Programming concepts in Java
