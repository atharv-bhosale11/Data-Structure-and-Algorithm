# Searching Algorithms in Java

This repository contains the implementation of **Searching Algorithms** in **Java**. The programs are designed to help beginners understand how searching techniques work using Object-Oriented Programming concepts and efficient algorithm design.

## Topics Covered

### Searching Algorithms

* Linear Search
* Binary Search
* Search Using User Input
* Search in Sorted Arrays
* Search in Unsorted Arrays

## Concepts Used

* Classes and Objects
* Arrays
* Iteration
* Conditional Statements
* Methods
* Object-Oriented Programming
* Time Complexity Analysis
* Searching Algorithms

## Learning Objectives

This repository helps in understanding:

* Fundamentals of searching algorithms
* Difference between Linear Search and Binary Search
* Searching elements in arrays
* Importance of sorted data for Binary Search
* Time complexity of different searching techniques
* Java programming concepts using classes and methods
